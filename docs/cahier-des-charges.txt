PROMPT CLAUDE CODE - PLATEFORME DE RECENSEMENT DES JEUNES DU FJCS

Tu es un Lead Software Engineer, Architecte Full-Stack, UX/UI Designer senior et Data Engineer.

Ta mission est de concevoir et développer une plateforme web professionnelle de recensement et d'analyse de la jeunesse pour :

FOYER DES JEUNES ET DE LA CULTURE DE SANGALKAM (FJCS)

Le projet est porté par la Commission Transformation Numérique et Innovation du FJCS.

IMPORTANT :
Il ne s'agit PAS d'un simple formulaire en ligne.

Je veux construire une véritable plateforme numérique de connaissance de la jeunesse de Sangalkam permettant :
- de recenser les jeunes ;
- de structurer leurs informations ;
- de produire automatiquement des statistiques ;
- d'analyser les besoins de la jeunesse ;
- d'identifier les compétences ;
- d'identifier les entrepreneurs et porteurs de projets ;
- d'identifier les besoins en formation et emploi ;
- de produire des rapports ;
- de permettre aux administrateurs du FJCS de piloter les données ;
- de fournir une base de données exploitable pour les futurs programmes et projets du FJCS.

Le produit doit être moderne, professionnel, rapide, sécurisé, responsive et réellement utilisable en production.

17. SÉCURITÉ
==================================================

La plateforme collecte des données personnelles.

La sécurité est donc une priorité.

Implémenter :
- validation serveur ;
- validation frontend ;
- protection contre SQL injection via ORM ;
- protection XSS ;
- CSRF lorsque pertinent ;
- rate limiting ;
- anti-spam ;
- CAPTCHA ou mécanisme équivalent si nécessaire ;
- headers de sécurité ;
- contrôle d'accès ;
- logs ;
- sessions sécurisées ;
- mots de passe hashés ;
- aucune donnée sensible dans les logs.

Ne jamais exposer les données personnelles dans une API publique.

Prévoir une politique de conservation et de suppression des données.

Prévoir une fonctionnalité permettant aux administrateurs autorisés de supprimer/anonymiser les données selon les règles définies par le FJCS.

Le système doit respecter les exigences applicables en matière de protection des données personnelles au Sénégal.
